# robics_learning

具身智能不是“会聊天的大模型”，而是：让一个身体，看见世界、理解指令、做出动作、在真实物理里把事做成。

学习人形机器人，从“大脑”开始研究会很迷茫，在此之前我们要先搞明白三件事：  

##1.身体节点怎么实现，全身框架怎么数字化？  
##2.动作从哪里来？  
##3.任务怎么学习？又怎么让机器人有“举一反三”的能力？  

那么我们理所当然就会想要了解：

1.**把实际人体模型化赋给机器人的方法？**试想：如果将整个实体分成无数个数据点，想要研究人体运动最关键的是哪些点？  
  （其实是无限思想下人体无数个点很难建模、储存和计算也会很复杂）  
2.**怎样直接将实体的数据输送给机器人？**  
我们必须使用一个平台作为信号转换的媒介，即仿真平台。  
**仿真平台有哪些？各自有什么优劣区别？**  
**数据从仿真平台传输给真机使得真机能够较理想地运动的方法？**  
3.**实现上面这些问题需要哪些硬件支持？** 比如对应的电机、电源和控制器。  
4.**如何通过更好的算法拟合数据提高机器人运动的稳定性？**  
5.实体能够做很多动作，先人肯定有所研究，他们的研究成果有哪些？**他们建立的动作库又在哪？**  
6.现在很流行ai学习，能不能把这种思想接入机器人的“大脑”，使得他们也能够 **学习很多动作然后尝试把它们做出来？**  
  实际生活中我们人体可以在不同的情境下对同一个动作进行微调，**机器人用什么方法能获得像人脑一样的感知能力并且能够输出有细微差别的动作？**  
  
......

类似的问题肯定还有很多很多，  
随着近年来深度学习、大模型的爆火，具身智能成为“类人”的未来或许越来越近。  
这意味着每一次相关领域的革新，我们都要跟上，并且灵活运用在人形机器人上。
