# 引言

具身智能不是“会聊天的大模型”，而是：**让一个身体，看见世界、理解指令、做出动作、在真实物理里把事做成。**

学习人形机器人，从“大脑”开始研究很迷茫，在此之前先弄清楚三件事：

- [ ] **身体怎么动？**
- [ ] **动作从哪来？**
- [ ] **任务怎么学习？** 又怎么让机器人有“举一反三”的能力？

那么我们理所当然想要了解：

| 序号 | 核心探讨问题 | 细节/试想 |
| :--- | :--- | :--- |
| 1 | **把实际人体模型化赋给机器人的方法？** | 试想：将实体分成无数数据点，最关键的是哪些？（无限思想下建模、储存和计算极复杂） |
| 2 | **怎样直接将实体的数据输送给机器人？** | 需仿真平台作媒介；关注平台优劣、数据向真机传输的方法 |
| 3 | **实现上述问题需要哪些硬件支持？** | 如对应的电机、电源和控制器 |
| 4 | **如何通过更好的算法拟合数据**提高机器人运动的稳定性？ | |
| 5 | **先人的研究成果与动作库在哪？** | 实体能做很多动作，前人已有研究 |
| 6 | **接入 AI 学习思想，学习动作并做出微调** | 机器人如何获像人脑一样的感知，输出有细微差别的动作？ |

......

> 类似的问题还有很多很多，<br>
> 随着近年来深度学习、大模型的爆火，具身智能成为“类人”的未来或许越来越近。<br>
> 这意味着每一次相关领域的革新，我们都要跟上，并且灵活运用在人形机器人上。

### 三层世界观
| 层级 | 核心定位 | 关键维度/要素 | 代表技术/概念 |
| :--- | :--- | :--- | :--- |
| **身体层** | 物理基础与感知 | 关节数、自由度、质量分布、电机响应；相机、IMU、力矩、触觉 | 硬件本体、传感器融合 |
| **控制层** | 运动执行与稳定 | 运动学、动力学、平衡、步态；Whole-Body Control；力矩/位置控制 | PHC/UHC、ExBody、OmniH2O |
| **智能层** | 认知决策与泛化 | 多模态语义（VLA）、任务规划（推理/世界模型）、泛化学习（举一反三/模仿学习）、长时序记忆 | HumanPlus、π0、GR00T、LLM |
